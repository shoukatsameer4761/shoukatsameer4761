## How I work

- **Native feel first** — Reanimated 2 and gesture handling at 60 FPS, platform-correct navigation, safe-area and device-size coverage from the first commit.
- **Measure, then optimize** — Flipper / React DevTools profiling, FlatList tuning, lazy loading and image caching before shipping.
- **Release discipline** — code signing, provisioning profiles, keystores, EAS / fastlane-style pipelines, monthly store releases with 80%+ test coverage.
- **AI-native** — Claude Code for scaffolding, refactors, test generation and review, with human review on every PR.
- **Still learning** — working through a structured ML / LLM / RAG curriculum in Python on the side; projects land here as they ship.
